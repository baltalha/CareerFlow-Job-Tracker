# CareerFlow — Job Tracker

A modern React-based job tracking and career management application designed to help users organize job applications, track their skills, analyze career readiness, and build personalized career roadmaps.

## 🚀 Features

* 📊 Dashboard with application statistics
* 💼 Job application tracking
* 🔎 Application search and filtering
* 📋 Application status management
* ⭐ Application priority management
* 📈 Career readiness analysis
* 🧠 Skill tracking
* 🗺️ Personalized career roadmaps
* 🎯 Career Simulator
* 🔍 Job Analyzer
* 🏆 Career Center
* 💾 LocalStorage data persistence
* 📱 Responsive user interface
* ✨ Modern animated SaaS-style UI

## 🛠️ Technologies

* React
* JavaScript
* React Router
* Vite
* CSS
* HTML
* LocalStorage

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/baltalha/CareerFlow-Job-Tracker.git
```

Navigate to the project folder:

```bash
cd CareerFlow-Job-Tracker
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## 🎯 Purpose

CareerFlow was developed as a portfolio project to demonstrate practical frontend development skills, modern React architecture, component-based development, routing, state management, and user-focused interface design.
